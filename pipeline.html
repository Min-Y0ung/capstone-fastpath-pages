캡스톤디자인2 · ㈜바르카 연계 · 2026년 11월 18일 기준

농작업자 사고 판정 Fast Path · 로컬 LLM

몸통 센서의 5초 기록을 숫자 요약으로 바꿔 LLM에 보여주고, 사고 유형·긴급도·권고 조치·판단 근거를 JSON으로 받아 알림으로 보내는 판정 모듈입니다. 공개 소형 모델(Qwen3.5 4B)을 우리 데이터로 파인튜닝해 로컬 GPU에서 실행하므로, 인터넷이나 외부 API 없이 1초 안에 판정합니다.

판정 모델 Qwen3.5 4B 파인튜닝 (로컬 GPU) 규모 비교 Ministral 3 8B 파인튜닝 (팀원 학습) 윈도우 5초 · 간격 2.5초 · 추세 60초 기상 기상청 ASOS 실측 테스트 32개 통과 사고 유형 5종
1. 전체 흐름

센서 신호가 알림이 되기까지 여섯 단계

LLM이 맡는 단계는 ④ 하나입니다. 나머지는 우리가 작성한 코드와 규칙이고, LLM이 실패해도 시스템이 멈추지 않도록 앞뒤를 감쌉니다.

코드 (계산·변환) 규칙 (사람이 정한 기준) LLM 판정
1

센서 입력과 윈도우 자르기

코드

허리·가슴에 단 IMU 1개(가속도·자이로, 100Hz)와 심박(1초 갱신), 기상청 ASOS 기온·습도·풍속을 받습니다. 2.5초마다 최근 5초를 잘라 한 건의 판정 단위로 만듭니다.

입력 acc[500×3] m/s² gyro[500×3] °/s hr[500] bpm + 직전 60초 기록 + 기상
2

특성 추출과 토큰 직렬화

코드

원본 신호를 그대로 주지 않고, 사고를 가르는 숫자로 요약합니다. 충격 크기, 자유낙하 시간, 회전 속도, 몸통 기울기 변화, 충격 뒤 움직임, 기계 진동, 심박 변화, 체감온도 등입니다. 이 숫자를 Rich Path와 같은 규격(fptok-1.0)의 텍스트로 바꿉니다.

<MOTION> acc_peak=3.28 freefall=30 gyro_peak=390 tilt0=21 tilt1=65 vib=2.65 | impact=STRONG rot=VERY_FAST vib_lvl=HIGH </MOTION>
3

게이트: 명확한 정상은 건너뛰기

규칙

충격·회전·기울기 변화가 작고 심박과 기온이 정상이면 LLM을 부르지 않고 바로 "정상"으로 처리합니다. 호출 비용과 지연을 줄이는 장치입니다.

건너뜀 · 합성 dev 14%, 스트리밍 시연 51%
실측 검증 · SisFall 실제 낙상 898건 중 건너뛴 사고 0건
4

LLM 판정

LLM

우리 데이터 4,257건으로 파인튜닝한 Qwen3.5 4B가 Ollama로 같은 컴퓨터에서 실행됩니다. 판단 기준은 학습으로 익혔기 때문에 짧은 지시문(약 600토큰)에 이번 윈도우의 토큰만 붙여 보냅니다. 출력은 JSON 스키마로 형식을 강제하고, 온도 0으로 같은 입력에는 항상 같은 판정을 냅니다.

{ accident_detected, accident_type, urgency_score 0–100, recommended_actions[1–3], rationale }
5

검증과 폴백

규칙

점수가 0~100을 벗어나면 잘라내고, 유형과 사고 여부가 어긋나면 바로잡습니다. 응답이 2.5초 안에 오지 않거나 오류·거부가 나면 기다리지 않고 바로 대체 판정으로 넘어갑니다.

임계값 판정 · 충격·심박 기준표로 즉시 판정
직전 판정 유지 · 10초 안에 사고 판정이 있었으면 경보 유지
6

이벤트 출력

코드

판정 결과에 긴급도 단계, 판정 경로(gate / llm / fallback), 지연 시간, 원본 토큰을 붙여 JSONL 이벤트로 내보냅니다. 알림과 Rich Path가 이 스트림을 받습니다.

schema_version=fastpath-event-1.0 urgency_level=emergency source=llm latency_ms=5528

    로컬 파인튜닝 LLM의 장점
    
      
      
        
    • 같은 구간에서 오탐률 21.4% → 0.0%. 더운 날 고강도 작업, 짐 내려놓기, 뛰어내리기를 정상으로 판정
      • 
        
    • 임계값이 전도로 오분류하던 끼임, 심박 이상으로 보던 온열질환을 대부분 맞힘
      • 
        
    • 인터넷·외부 API·호출 비용 없이 동작하고, 작업자 데이터가 밖으로 나가지 않음
      • 
        
    • GPU 1대로 약 1시간이면 재학습 가능 → 현장 데이터를 받으면 바로 다시 맞출 수 있음
      •
